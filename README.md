# 📉 Telco Customer Churn & Retention Analytics

End-to-end customer churn analysis on the IBM Telco dataset using **SQL Server, Python, and Power BI**: from raw CSV to business insights, statistical tests, baseline ML models, and an interactive dashboard.

![Dashboard](images/dashboard.png)

---

## 📌 Project Overview

A telecom company is losing roughly **1 in 4 customers**. This project finds out **who is leaving, why, and how much revenue is at risk**, so the retention team can focus on the right customers.

**Business questions answered**
- What is the overall churn and retention rate?
- Which contract types, payment methods, and internet services have the highest churn?
- How does tenure affect churn? When are customers most at risk?
- Do add-on services (Online Security, Tech Support) reduce churn?
- Which customer segments should be prioritised for retention campaigns?

## 🔄 Project Workflow

### 1️⃣ SQL Analysis (`Telco_Churn.sql`)
- Imported the CSV into SQL Server and renamed the table to `Telco_Customer_Churn`
- Overall churn rate and total customers
- Churn by **Contract**, **PaymentMethod**, **InternetService**
- Contract × Payment Method **risk ranking** using `RANK() OVER()`
- Top 100 churned customers by monthly charges
- Used `TRY_CAST` to handle blank `TotalCharges` values

### 2️⃣ Python Analysis (`Churn_Analysis.py`)

| Step | What was done |
|---|---|
| Data cleaning | Stripped whitespace, fixed `TotalCharges` (blank → `MonthlyCharges × tenure`), removed duplicates, created `Churn_Flag` |
| Feature engineering | `Tenure_Group`, `MonthlyCharge_Group`, `Annual_Revenue`, `Revenue_Lost`, `Estimated_LTV`, `Service_Count`, `Support_Count`, `Streaming_Count`, `Customer_Value_Band`, and binary flags |
| Segment analysis | 20 group-by analyses (customers, churn rate, retention, avg charges, revenue lost) |
| Descriptive stats | Mean, median, mode, variance, IQR, skewness, kurtosis for key numeric columns |
| KPIs | Churn rate, retention rate, ARPU, monthly/annual revenue, revenue lost, average LTV |
| Hypothesis testing | t-tests (numeric vs churn) and Chi-square tests (categorical vs churn) |
| Correlation | Correlation matrix of all numeric and engineered features |
| Segmentation | Customer risk segments |
| Machine learning | Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, Extra Trees |
| Model tuning | Stratified cross-validation and hyperparameter tuning |
| Unsupervised | K-Means clustering and PCA |
| Outliers | IQR-based outlier detection |
| Reporting | Data-quality checks and an automated business report |

### 3️⃣ Power BI Dashboard (`.pbix`)
Interactive dashboard with slicers for **Partner, Contract, and Gender**.

**KPI cards:** Retention Rate, Total Customers, Retained Customers, Avg Monthly Charges, Monthly Revenue

**Visuals:** Churn by Contract, Customers by Contract, Churn by Payment Method, Churn by Internet Service, Churn by Tenure (line), Customers by Senior Citizen

## 📊 Key Findings

| Driver | Insight |
|---|---|
| **Contract** | Month-to-month customers churn far more than One-year or Two-year. Almost all churn comes from this group. |
| **Tenure** | Churn is highest in the first 12 months and falls steadily after that. |
| **Payment method** | Electronic check has the highest churn. The other three methods are much lower and similar to each other. |
| **Internet service** | Fiber optic customers churn the most, well above DSL and no-internet customers. |
| **Add-on services** | Customers without Online Security or Tech Support churn much more than those with them. |
| **Billing** | Paperless billing customers churn more than paper billing customers. |
| **Family status** | Customers with no partner or no dependents churn more. |
| **Senior citizens** | A smaller group, but with a noticeably higher churn rate. |
| **Gender** | No meaningful difference between Female and Male. |
| **Customer value** | The lowest value band (low LTV, mostly new customers) has the highest churn. |

> The overall retention rate is about **73%** (churn about 27%), with about **$456K** in monthly revenue across roughly 7K customers.

### 🎯 Recommendations
1. **Convert month-to-month customers** to 1 or 2-year plans with discounts or loyalty benefits.
2. **Build a strong first-year onboarding programme**, since the first 12 months carry the highest risk.
3. **Push customers from electronic check to auto-pay** (bank transfer or credit card) with small incentives.
4. **Bundle Online Security and Tech Support** for fiber optic customers.
5. **Investigate fiber optic service quality and pricing**, because it has the highest churn despite being the premium product.
6. **Target new, low-value, no-partner customers** with early-tenure retention offers.

## ▶️ How to Run

**1. Clone the repository**
```bash
git clone https://github.com/<your-username>/Telco-Customer-Churn-Analysis.git
cd Telco-Customer-Churn-Analysis
```

**2. Install dependencies**
```bash
pip install pandas numpy scipy matplotlib seaborn scikit-learn
```

**3. Run the Python analysis**

Place the CSV in the same folder as `Churn_Analysis.py`, then run:
```bash
python Churn_Analysis.py
```
Charts are saved to `outputs/charts/`.

**4. Run the SQL analysis**
- Import the CSV into SQL Server (Import Flat File Wizard) and name the table `Telco_Customer_Churn`
- Open `Telco_Churn.sql` in SSMS and run each query one at a time (select, then press F5)

**5. Open the dashboard**
- Open the `.pbix` file in Power BI Desktop
